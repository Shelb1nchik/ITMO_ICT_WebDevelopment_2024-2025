Доска Заданий

"Доска Заданий" — система для управления студенческими задачами. Проект включает как frontend-часть, реализованную на React, так и backend-часть на Java с использованием Jakarta RESTful Web Services и JWT для аутентификации. В приложении студенты могут регистрироваться, просматривать задания, отправлять выполненные работы и следить за своими оценками. Администраторы и преподаватели получают доступ к инструментам для создания и назначения заданий, изменения их статусов, а также мониторинга успеваемости студентов через удобную административную панель.

Функциональность

  • Аутентификация и регистрация пользователей Пользователи могут создать аккаунт и авторизоваться через форму входа с выбором роли: Student или Teacher.

  • Работа с заданиями

  • Для Teacher:
    • Создание новых заданий с указанием заголовка и срока выполнения.
    • Просмотр списка активных заданий.
    • Просмотр и оценка отправленных заданий студентов.
  • Для Student:
    • Просмотр актуальных заданий с указанием сроков выполнения.
    • Отправка выполненных заданий (содержащих текстовый ответ).
    • Просмотр списка своих отправок и оценок.
    • Просмотр статистики успеваемости класса (средняя оценка по каждому заданию).

Архитектура проекта

Frontend

Реализован с использованием React. Основные компоненты: - InteractiveBackground – интерактивный фон на основе HTML5 canvas, реагирующий на движения мыши. - LoginForm и RegisterForm – формы для входа и регистрации пользователей с выбором роли и класса для учеников. - StudentPage – панель для студентов, включающая: - Список заданий с возможностью отправки решения. - Таблицы для отображения собственных отправок и статистики успеваемости класса. - TeacherPage – панель для учителей, позволяющая: - Создавать новые задания. - Просматривать активные задания и их отправки. - Оценивать работы студентов.

API-вызовы осуществляются с помощью axios через модули: - assignmentsApi.js – получение списка заданий и создание новых заданий. - submissionsApi.js – отправка решений, выставление оценок и получение отправок. - performanceApi.js – запрос статистики успеваемости класса.

Backend

Реализован на Java с использованием Jakarta RESTful Web Services. Основные компоненты: - Контроллеры (Controllers): - AssignmentController: Обрабатывает создание и получение заданий. Для создания задания проверяется, что запрос исходит от пользователя с ролью Teacher. - SubmissionController: Позволяет студентам отправлять выполненные задания и учителям оценивать их. Также обеспечивает получение отправок по заданию или для конкретного студента. - PerformanceController: Предоставляет статистику по успеваемости класса для текущего студента. - UserController: Обрабатывает регистрацию и аутентификацию пользователей, возвращая JWT при успешном входе. - ProtectedController: Пример защищенного эндпойнта, доступного только после аутентификации. - Сущности (Entities): - Assignment: Задание, содержащее заголовок, срок выполнения и информацию о создателе (Teacher). - Submission: Отправка задания студентом, содержащая текст ответа, дату отправки и оценку (если проверено). - User: Пользователь системы с ролями Teacher или Student. Для студентов дополнительно указывается номер класса. - Сервисы (Services): - AssignmentService, SubmissionService, PerformanceService и UserService – бизнес-логика для работы с заданиями, отправками, статистикой и пользователями. - Аутентификация:
Использование JWT с использованием класса JwtUtil для проверки авторизации запросов. Из каждого запроса извлекается Bearer-токен, который валидируется перед выполнением операций.

Установка и запуск проекта

1) Клонирование репозитория

bash git clone https://github.com/yourusername/proj2.git

2) Запуск frontend

bash cd proj2/frontend npm start

3) Запуск backend

1) Настроить подключение к вашей БД через persistence.xml
2) Собрать проект и развернуть его на сервере приложений WildFly или Tomcat
